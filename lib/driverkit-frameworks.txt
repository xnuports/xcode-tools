# The DriverKit SDK's frameworks, one "<Framework>/<path under Headers>"
# per line.
#
# These are not Objective-C and no class-dump produces them: a DriverKit
# framework header is a C++ class declaration, generally paired with the .iig
# the interface generator reads, and it carries Apple's OSReference licence
# header -- they ship as source, in the same open-source drops the driver
# families come from, not as metadata inside a binary.
#
# So they are gathered the way IOKit.framework's headers are: looked for by
# name across the drops this tree has, and installed at the path the manifest
# gives.  What Apple has not released cannot be found, and is reported.
