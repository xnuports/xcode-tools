# The public headers of IOKit.framework.
#
# One path per line, relative to the framework's Headers directory,
# exactly as Apple ship them.  This is a list of names -- a fact about
# the platform, like the set of libSystem sub-libraries -- and it is
# recorded here because it cannot be derived at build time: the driver
# families each lay their sources out differently, and installing
# everything they contain would carry in the kernel-side headers Apple
# publish but do not ship in the SDK.
#
# mk/scripts/install-iokit-headers.sh installs what it can find of this
# and says what it could not.  Anything absent belongs to a project not
# in this tree.
