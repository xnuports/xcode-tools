# The WatchOS SDK's usr/include, one path per line, relative to
# usr/include inside the SDK.
#
# These are the macOS C headers restricted to what this platform is allowed
# to reach for.  The list is what distinguishes the two SDKs, so it is kept
# here rather than derived -- there is no rule that produces it, only Apple's
# choice of what to ship.
#
# Not only *.h: libc++'s headers have no extension, and leaving them out
# leaves every c++/v1 shim unable to find <__config>.
#
# mk/scripts/install-sdk-headers.sh installs these out of the macOS SDK this
# build has already assembled from source.  What is not there is reported.
